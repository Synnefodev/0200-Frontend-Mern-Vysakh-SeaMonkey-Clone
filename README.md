# SeaMonkey Landing Page Clone

## Project Overview

The objective of this project is to recreate the SeaMonkey Expedition landing page using modern frontend development practices. Students will work collaboratively through GitHub Issues, implementing each section of the website while following responsive design principles and clean coding standards.

---

## Learning Objectives

By completing this project, students will:

* Practice semantic HTML structure
* Build responsive layouts using CSS
* Improve UI implementation skills
* Learn component-based development
* Work with Git and GitHub workflows
* Collaborate using Issues and Pull Requests
* Develop debugging and problem-solving skills
* Follow industry-standard frontend development practices

---

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

---

## Project Structure

Students will complete the project through the following GitHub Issues:

### Issue #1 - Create the Navigation Bar

Develop a fully responsive navigation bar.

#### Requirements

* Create the website logo section
* Add navigation links
* Implement a mobile hamburger menu
* Add hover and active states
* Ensure proper responsiveness

---

### Issue #2 - Create the Hero Section

Develop the hero section that serves as the first visual element users see when visiting the website.

#### Requirements

* Background image/banner
* Main heading
* Supporting text
* CTA button(s)
* Proper spacing and alignment

---

### Issue #3 - Create the About Section

Build the About section that introduces the expedition and its purpose.

#### Requirements

* Section heading
* Description content
* Supporting image(s)
* Responsive layout

---

### Issue #4 - Create the Expedition Section

Develop the Expedition section showcasing expedition-related information.

#### Requirements

* Information cards/content blocks
* Images and descriptions
* Consistent styling
* Responsive layout

---

### Issue #5 - Create the Gallery Section

Create a gallery section displaying expedition images.

#### Requirements

* Responsive image grid
* Proper image spacing
* Hover effects
* Mobile-friendly layout

---

### Issue #6 - Create the FAQ Section

Develop an FAQ section using accordion functionality.

#### Requirements

* Questions and answers
* Expand/Collapse functionality
* Responsive design
* Accessible interaction

---

### Issue #7 - Create Contact Section and Footer

Develop the Contact section and Footer.

#### Contact Section

* Contact form
* Input validation
* Submit button

#### Footer

* Navigation links
* Social media links
* Copyright information

---

### Issue #8 - Make the Entire Website Fully Responsive

Review and optimize all sections for responsiveness.

#### Requirements

* Mobile optimization
* Tablet optimization
* Desktop optimization
* Fix overflow issues
* Improve spacing and typography
* Ensure proper image scaling

## Responsive Design Requirements

The website must support:

| Device  | Screen Width     |
| ------- | ---------------- |
| Mobile  | 320px - 767px    |
| Tablet  | 768px - 1023px   |
| Desktop | 1024px and above |

### Checklist

* No horizontal scrolling
* Images scale correctly
* Navigation works on all devices
* Typography remains readable
* Proper spacing is maintained
